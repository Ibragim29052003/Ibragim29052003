### 🚀 Основные проекты

#### 📊 SellerStatus — единая система для селлеров Wildberries

Продуктовая система, которая собирает данные из WB API, хранит их в PostgreSQL, строит отчеты и отправляет уведомления. В нее входят публичный сайт, закрытый веб-кабинет с аналитикой, API, фоновые воркеры и Telegram-бот.

**Стек:** Python 3.12, FastAPI, aiogram 3, SQLAlchemy 2, PostgreSQL, Alembic, React 19, TypeScript, Redux Toolkit, Vite, Docker Compose, Wildberries API, Telegram Bot API.

[🌐 Сайт](https://sellerstatus.ru) · [📈 Веб-сервис](https://app.sellerstatus.ru) · [🤖 Telegram-бот](https://t.me/SellerStatusBot)

#### 👗 TaSaHa — full-stack каталог одежды

Каталог с витриной товаров, фильтрами, поиском, слайдерами и страницами товаров. Django-бэкенд предоставляет API и админ-панель, синхронизирует товары, цены и остатки из Wildberries; React-приложение отображает подготовленные данные.

**Стек:** React, TypeScript, Vite, Redux Toolkit, RTK Query, SCSS, Django, PostgreSQL, Docker, Wildberries API.
